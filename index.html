🎢 Exponat: Paternoster

Kiosk-Software für interaktive Paternoster-Exponate mit Live-MQTT Sensordaten.

🏗️ Komponenten-Architektur

1. Frontend (`app-vue`): Visualisiert rotierende Fahrzeugkarossen im Paternoster-Umlaufaufzug. Es verarbeitet MQTT-Nachrichten live über WebSocket.

2. Backend / CMS (`cms-v5`): Strapi v5 Headless-CMS mit SQLite-Datenbank (`.tmp/data.db`) für mehrsprachige Texte und Medien-Uploads.

⏳ Smart-Sync & Inaktivitäts-Timer

- Auto-Reset (120 Sekunden): Springt bei Inaktivität auf die Standardansicht und die aktuell physisch sichtbare Karosse zurück.
- Smart-Sync: Solange ein Besucher liest oder wischt, werden MQTT-Auto-Wechsel geparkt, um die Interaktion nicht zu unterbrechen.

💻 Betrieb & Weston Kiosk-Setup (Ubuntu Linux)

Komplette Anleitung zum Einrichten eines nahtlosen Wayland/Weston Kiosk-PCs ohne sichtbaren Mauszeiger.

1. Chromium Kiosk Startskript (`/usr/local/bin/kiosk-start.sh`)

Bash Skript
#!/bin/bash source /etc/default/kiosk 2>/dev/null URL=${KIOSK_URL:-"http://localhost:8081"} timeout=120; elapsed=0 until curl -sf "$URL" > /dev/null 2>&1; do sleep 2; elapsed=$((elapsed+2)) if [ "$elapsed" -ge "$timeout" ]; then exit 1; fi done exec chromium-browser \ --enable-features=UseOzonePlatform \ --ozone-platform=wayland \ --kiosk \ --incognito \ --no-first-run \ --disable-infobars \ --disable-translate \ --disable-features=Translate,TranslateUI \ "$URL"

2. Chromium Translation Banner erzwingend deaktivieren

Ubuntu Policy Setup
sudo mkdir -p /etc/chromium-browser/policies/managed/ sudo mkdir -p /etc/chromium/policies/managed/ echo '{ "TranslateEnabled": false }' | sudo tee /etc/chromium-browser/policies/managed/disable_translate.json echo '{ "TranslateEnabled": false }' | sudo tee /etc/chromium/policies/managed/disable_translate.json

🛠️ Troubleshooting Matrix

Häufige Fehlerbilder und deren direkte Lösung auf dem Kiosk-PC.

Symptom / Problem Mögliche Ursache Lösungsschritte
Kiosk stellt alte CMS-IP dar `databaseIP` in `settings.json` editiert, aber Vue-App nicht neu kompiliert. Vue-Image neu bauen (`docker compose build app-vue`), da die IP beim Build fest in das Frontend eingebrannt wird.
MQTT-Verbindung schlägt fehl Browser blockiert reine TCP (`mqtt://`) Protokolle. Mosquitto auf WebSockets umstellen und `mqttBrokerUrl` in `settings.json` mit `ws://` konfigurieren (z.B. `ws://10.1.1.90:9001`).
Festplatte nach Docker-Update voll Unbenutzte Docker Container und Images akkumulieren sich. Vor `docker load` immer `docker rm -f ` und `docker system prune -a -f` ausführen.
Chromium zeigt Übersetzungssprache an Chromium ignoriert CLI Parameter `--disable-translate`. Managed JSON Policy unter `/etc/chromium/policies/managed/disable_translate.json` mit `"TranslateEnabled": false` anlegen.
Horch 8 Video ruckelt Fehlende Hardware-GPU Acceleration im Docker Container. Gerät `/dev/dri` und Wayland-Socket im Container einbinden.
